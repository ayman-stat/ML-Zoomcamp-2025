# ML Zoomcamp 2025

Personal learning and portfolio workspace for the DataTalks.Club Machine Learning Zoomcamp.

This repository tracks my applied ML engineering practice across supervised learning, model evaluation, deployment, deep learning, serverless inference, Kubernetes, and model serving. It is intentionally structured to show progress and implementation work while linking back to the official course materials.

## Portfolio Direction

The target outcome is not only to finish exercises, but to turn the repo into a credible ML engineering portfolio:

- Clean notebooks with problem statements and business framing.
- Reproducible scripts for training and inference.
- Clear model metrics and validation results.
- Deployment-ready examples where practical.
- A final project that connects to my CV positioning: churn prediction, customer retention, credit risk analytics, or business performance forecasting.
